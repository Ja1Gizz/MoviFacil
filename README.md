##  Sobre o projeto

O Movi Fácil é um projeto desenvolvido com o objetivo de incentivar o uso do transporte público de forma mais acessível, econômica e inteligente.

A ideia principal do sistema é transformar viagens de ônibus e metrô em benefícios reais para os usuários. A cada utilização do transporte público, o usuário acumula pontos que podem ser trocados por descontos em passagens ou até mesmo por viagens gratuitas.

Além de beneficiar os usuários, o projeto também busca incentivar uma mobilidade urbana mais sustentável, ajudando na redução do trânsito e da emissão de poluentes.

---

## Objetivo

O projeto foi criado para:

- Incentivar o uso do transporte público;
- Tornar o transporte mais acessível financeiramente;
- Reduzir o uso de veículos particulares;
- Melhorar a mobilidade urbana;
- Oferecer vantagens e recompensas aos usuários.

---

## Funcionalidades

- Sistema de pontos por utilização do transporte;
- Missões e desafios dentro da plataforma;
- Resgate de descontos em passagens;
- Possibilidade de troca de pontos por viagens gratuitas;
- FAQ interativo;
- Formulário de contato;
- Interface moderna e responsiva.

##  Sobre as páginas do site

### Página Inicial
A página inicial apresenta o projeto e mostra os principais benefícios do Movi Fácil, com uma navegação simples e intuitiva.

### Página Sobre
Explica a motivação do projeto, os problemas relacionados ao transporte público e os objetivos da solução.

### Página Solução
Mostra como o sistema funciona, explicando o sistema de pontos, missões e benefícios oferecidos ao usuário.

### Página FAQ
Contém perguntas frequentes sobre o funcionamento da plataforma e utiliza JavaScript para interação.

### Página Contato
Disponibiliza um formulário para envio de mensagens e informações para contato com a equipe.
